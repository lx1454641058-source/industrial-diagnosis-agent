## SEN0438 已核实参数

以下仅针对该候选型号，不可套用到所有 RS485 温湿度传感器。来源为厂家商品页及其直接链接的[中文使用说明](https://img.dfrobot.com.cn/wikicn/5ea64bf6cf1d8c7738ad2881/c79ead8f8786c463e677989e74636608.pdf)，页码按 PDF 物理页计算。

| 参数 | 核查结果 |
|---|---|
| 电源 | 12～36V DC；商品页最大电流消耗 20mA 内 |
| 采样周期 | 3 秒；初期建议软件每 3～5 秒读取一次 |
| 默认波特率 | 9600 bit/s |
| 串口格式 | 手册未明确数据位、校验位、停止位；8N1 只能作为待核验的候选配置 |
| 设备地址 | 地址由 8 位拨码设置；地址 1 是通信示例，不等于已证明的出厂默认值 |
| 数据读取 | 功能码 0x03，连续读两个寄存器 |
| 寄存器 | 湿度 0x0000；温度 0x0001 |
| 地址解释 | 请求报文直接发送 0x0000 起始地址，即 PDU 零基地址；不要发送 40001，也不要额外减 1 |
| 顺序及缩放 | 先湿度、后温度；每个 16 位数据除以 10 |
| 字节顺序 | 每个寄存器高字节在前；帧末 CRC 校验码低字节在前 |
| 负温度编码 | 手册描述为 16 位正负数输出，但没有负数报文或明确的二补码说明；需供应商或实物验证 |
| 写操作 | 手册另列 0x10；本毕设第一版只读，不开放传感器寄存器写入 |

PDU 指协议中携带功能码和地址等内容的数据单元。CRC 是检测报文传输差错的校验值。

官方读取示例（手册第 4～5 页）：

```text
请求：01 03 00 00 00 02 C4 0B
响应：01 03 04 01 D7 00 D6 CA 69
结果：湿度 0x01D7 / 10 = 47.1 %RH；温度 0x00D6 / 10 = 21.4 ℃
```

手册存在局部编辑错误：响应表将 4 数据字节称为 4 个寄存器、第二个寄存器备注重复写湿度，湿度计算展开式也有笔误。项目依据寄存器映射、总长度和示例结果交叉确定“2 个寄存器、先湿后温”。传输 /10 不代表实际测量准确度达到 0.1%RH；商品页的湿度显示分辨率另写为 1%RH。

## 接线与首次调通

1. 先核对到货型号、设备标签、手册版本、转换器端子说明及电源极性。未核对前不上电。
2. 在断电状态下连接 SEN0438：黄色接 RS485 A，白色接 RS485 B，红色接匹配电源正极，黑色接电源负极。转换器地线/隔离端的连接方式以其厂家接线说明为准，不猜测端子用途。
3. 固定并绝缘端子，检查无散股、短路和裸露电源导线。使用成品电源，不自行接市电端。
4. 接入 USB，记录操作系统实际分配的串口名、转换器标识。串口名可能在拔插后变化，不能永久假定为 COM3。
5. 确认传感器供电后，记录实际拨码地址和串口格式。先用只读配置请求功能码 0x03、起始地址 0、数量 2；每次只改一个软件通信参数。
6. 保存请求/响应十六进制报文，校验地址、功能码、长度和 CRC，再解码。无合法响应不产生新的有效温湿度记录。
7. 正常后连续采集至少 10 分钟，观察页面与历史记录。正常常温数据一致不能证明负温度编码正确；如未做低温验证，明确保留该限制。

不要为了验证负温度把此探头浸水、放入易结露环境或使用明火/高温热源。对照普通温湿度计只能作为合理性比较，不能声明完成计量校准。

## 受控故障实验

每次只注入一个故障，先记录正常配置，恢复后再进行下一项。仅限独立桌面实验，不操作生产设备。下表是拟定实验，不是已完成结果。

| 场景 | 操作方式 | 可接受结论 | 恢复及验收 |
|---|---|---|---|
| 转换器消失 | 拔出电脑端 USB | 当前串口不可见；建议检查 USB 连接 | 重新接入、核对串口，连续 3 次有效采样 |
| 传感器断电 | 用成品电源的低压开关断电，保留 USB | 串口仍可见但读取超时；供电是候选原因，不能单凭超时确定 | 重新供电并连续 3 次成功 |
| 采集停止 | 使用应用提供的停止功能 | 采集进程/任务未运行，历史值为旧数据 | 恢复采集，检查时间戳推进 |
| 软件地址错误 | 仅将电脑读取地址改为已知不匹配值 | 与已记录设备地址不一致；若缺少基准，只能列为可能原因 | 恢复软件地址，不修改设备拨码 |
| 波特率不匹配 | 仅改电脑端读取参数 | 配置与基准不同，通信可能失败 | 恢复已验证配置 |
| 恢复复查 | 人工处理后发起只读复测 | 基于新的有效样本确认通信恢复 | 报告列出复测时间、次数、结果 |

第一版不需要故意短接、反接、带电拆线或写入设备配置来制造故障。CRC 错误、错误长度、负温度等边界可先用软件报文测试覆盖，必须标明是模拟测试，不计作实物故障验证。

建议验收记录包含：实物型号及标签、接线照片、实际串口参数、正常原始报文、故障操作时间、日志与工具调用、智能体结论、恢复样本、未能确定的原因。敏感信息不进入照片、日志或报告。
