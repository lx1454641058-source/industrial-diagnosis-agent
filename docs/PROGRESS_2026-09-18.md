# 第一阶段软件与资料交付

本阶段完成软件基础、真实设备接入接口和智能体工具循环；尚未完成真实硬件与实际大模型验收。

## 已实现

- 独立项目目录，未修改父目录无人机代码。
- 只读 Modbus RTU 请求及响应解析，包括 CRC、地址、功能码、长度、异常帧和数据范围校验。
- 真实串口后端与明确标注的模拟后端；错误不覆盖最后有效记录，旧数据保留时间标签。
- SQLite 本地存储采集记录、原始响应、会话与工具证据，模拟与真实模式隔离。
- 六类诊断工具：采集状态、串口枚举、近期记录、配置比较、资料检索和三次间隔复测。
- Ollama 本机工具调用适配器，有界调用循环与证据编号检查。适配器已有脚本端点测试，未运行真实模型。
- 本地监控页面：温湿度趋势、采集记录、故障模拟、排查轨迹、历史报告与 JSON 下载入口。
- 候选硬件官方协议核查及原创建议；pySerial 3.5 安装于项目 `.runtime`。

## 实际验证

执行位置为项目目录，使用 Codex 附带 Python；串口依赖路径加入本次进程的 PYTHONPATH。

| 检查 | 实际结果 | 证明范围 |
|---|---|---|
| `python -m unittest discover -s tests -v` | 26 项通过，无跳过 | 协议、采集、工具、模型接口契约、HTTP 接口 |
| `node --check static/app.js` | 通过 | JavaScript 语法 |
| `python experiments/run_scenarios.py` | 七个模拟场景结构检查通过 | 规则基线的软件流程，不是模型准确率 |
| 浏览器操作 USB 串口消失场景并开始排查 | 页面显示串口不可见，带 E2 枚举证据 | 浏览器与后端联通 |
| 切回正常场景并点击处理后复查 | 页面显示三次间隔读取有效、恢复条件满足 | 模拟恢复流程 |
| 浏览器 console 检查 | 检查时无 error/warn | 本次桌面浏览器流程 |
| 串口枚举 | 仅发现 COM3/COM4 蓝牙串口 | 未识别到 USB RS485，不打开这些端口 |
| 本机 Ollama 检查 | 默认端口不可达，PATH 未找到程序 | 没有已确认可用的本地模型服务 |

实际模拟实验记录在 `work/experiments/20260918T071433466864Z/results.json` 与同目录 `REPORT.md`。

## 已解决的检查问题

读取安装包预想位置的 LICENSE.txt 时发现 wheel 不包含该文件。官方 v3.5 仓库许可证已核查；许可证副本另存于 `docs/third-party/pyserial-3.5-LICENSE.txt`。此问题不影响串口包安装或功能测试。
