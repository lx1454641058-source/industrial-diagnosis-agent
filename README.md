当前展示方式：采集与诊断源码；硬件演示本地运行。

## 本人责任

围绕低成本传感器采集中的通信和参数异常，负责场景拆解、采集与诊断流程、证据字段及工具权限设计；借助 AI 推进协议、模拟后端、网页和模型接口。

## 具体任务 1：拆分故障来源

把系统分成 Modbus RTU 协议、采集线程、数据存储、知识摘要、诊断工具、模型循环与网页。明确原始数据、有效状态、人工参考与历史记录之间的关系。

## 具体任务 2：设计只读与有效性

围绕地址、寄存器、CRC 校验、数据换算和超时拆解排查点，只允许 03/04 只读功能码。模拟与真实数据分目录保存；缺少独立参考时不以配置自比较认定正确。

## 具体任务 3：区分证据与模型解释

限定工具、参数、次数和时间；保留会话、工具轨迹与证据编号。网页区分直接记录与模型解读，模型失败明确报错，不能靠规则答案冒充模型成功。

## 演示与当前缺口

本地演示可展示超时 / 参数异常、工具轨迹和 JSON 报告。真实传感器与模型解释准确性需独立验收；模拟流程或脚本模型测试不能当作现场调试和长期可靠性证明。暂无已核实公网链接。

## 查看与运行

安装 Python 3.10+，默认运行 `./run.ps1 -Mode demo`。详细说明见 [本地运行说明](LOCAL-RUN.md)。硬件、串口、模型运行时另行配置，不随仓库分发。
